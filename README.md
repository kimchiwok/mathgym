# Math Gym

Learn math at your level: an age-matched placement test, short lessons, practice with worked solutions, and progress tracking. English, Русский, Қазақша.

**Open the app:** https://kimchiwok.github.io/mathgym/

On a phone, open the link and use **Add to Home Screen** (Safari → Share on iPhone, Chrome → ⋮ on Android). Progress is saved on each device.
